# طراحیِ صفحه در خانه‌یار

## اصلِ حاکم

این پروژه طرحِ تازه لازم ندارد؛ **سیستم** لازم دارد. هر عددی که در CSS می‌نویسی
باید از یک نردبانِ از‌پیش‌بستهٔ فاصله، تایپ، شعاع و زمان بیرون آمده باشد، و هر
صفحه‌ای که تحویل می‌دهی باید **عکسش را دیده باشی**. فارسی و راست‌به‌چپ هم
پیش‌فرض است، نه لایه‌ای که آخر کار اضافه شود.

## کِی این اسکیل را باز کن

- دست‌زدن به هر فایلی زیر `site/`
- ساختن یا بازچینیِ هر صفحه/شیت/مودالِ تازه در `src/features/`
- وقتی کاربر عکس یا لینکِ یک سایت را می‌فرستد و می‌گوید «ازین ایده بگیر»

**باز نکن برای:** عوض‌کردنِ یک رنگ یا یک padding، متنِ فارسیِ یک دکمه، یا هر
چیزی که هیچ چیدمانی را جابه‌جا نمی‌کند.

## قاعدهٔ مرکزی — هیچ عددِ خامی

```css
/* غلط — عددِ چشمی، هر بار یک چیزِ تازه */
.dl-card { padding: 18px; border-radius: 9px; gap: 7px; font-size: 13.5px; }

/* درست — از نردبان */
.dl-card { padding: var(--sp-6); border-radius: var(--r-card);
           gap: var(--sp-2); font-size: var(--fs-2); }
```

اگر عددی که لازم داری در نردبان نیست، یعنی یا اشتباه انتخاب کرده‌ای، یا نردبان
باید عوض شود — و عوض‌کردنش یک تصمیمِ جداست که در `:root` نوشته می‌شود، نه وسطِ
یک کلاس.

## مرجعِ سریع

| تصمیم | قانون |
|---|---|
| فاصله | فقط `--sp-1..10` = ۴ ۸ ۱۲ ۱۶ ۲۰ ۲۴ ۳۲ ۴۴ ۶۴ ۹۶ |
| اندازهٔ فونت | فقط `--fs-1..7` = ۱۱٫۵ ۱۳ ۱۴ ۱۶ ۱۸ ۲۱ ۲۶ + یک `clamp()` برای h1 |
| ارتفاع خط فارسی | متن ۱٫۸۵–۱٫۹۵ · تیتر ۱٫۴–۱٫۵ · **هرگز زیر ۱٫۳۵** |
| letter-spacing روی فارسی | **صفر.** نه منفی، نه مثبت |
| شعاع | دکمه/اینپوت `--r-btn` ۸ · کارت `--r-card` ۱۲ · قرص `--r-pill` — سه‌تا، تمام |
| حرکت | `--dur-fast` ۱۶۰ms ریز · `--dur-med` ۲۸۰ms تغییرِ حالت · فقط `transform` و `opacity` |
| هدفِ لمس | ≥ ۴۴×۴۴ پیکسل |
| کنتراست | متن ۴٫۵:۱ · تیترِ درشت و آیکون و حاشیهٔ اینپوت ۳:۱ |
| رنگِ تأکید | فقط یکی: `--green`. آبی/بنفشِ تزئینی ممنوع |
| عرضِ سطر | پاراگراف حداکثر `44em` |

## روندِ کار

1. **اول بخوان:** `references/tokens.md` — کدام توکن کجاست و چرا دو فایلِ CSS داریم.
2. اگر متنِ فارسی، عدد، یا نشانیِ لاتین در کار است: `references/rtl-fa.md`.
   این را رد نکن؛ هیچ‌یک از مراجعِ بیرونیِ طراحی یک کلمه دربارهٔ راست‌به‌چپ ندارند.
3. طرح را **قبل از کد** در دو خط بنویس: چه چیزی قهرمانِ صفحه است و بقیه چطور
   ساکت می‌مانند. یک جسارت، بقیه آرام.
4. کد را بنویس. هر بلوکِ تازه در CSS با یک کامنتِ فارسیِ کوتاه شروع شود که
   می‌گوید مالِ کدام بخش است و چه قاعده‌ای دارد.
5. **قبل از گفتنِ «تمام شد»:** `references/review.md` را باز کن و همان‌جا
   عکس‌ها را بگیر. تحویلِ بی‌عکس ممنوع.

## اشتباه‌های تکراری

| فکری که می‌کنی | واقعیت |
|---|---|
| «یک ۱۳٫۵ پیکسل که چیزی را خراب نمی‌کند» | همین‌طور بود که این فایل بیست اندازهٔ فونت پیدا کرد. از نردبان بردار. |
| «در ذهنم درست به نظر می‌رسد» | `node tools/shot.cjs` را بزن و در عرضِ ۳۶۰ نگاهش کن. |
| «سه کارتِ مساویِ کنار هم چیدمانِ استانداردی است» | استانداردترین چیدمانِ ماشین‌ساخته است. با فاصله و یک خطِ نازک گروه‌بندی کن، نه با کارت. |
| «عدد را با `tabular-nums` مونواسپیس می‌کنم» | فونتِ مونوی لاتین فارسی ندارد؛ فقط داخلِ `<span dir="ltr">` مجاز است. |
| «یک برچسبِ ALL-CAPS بالای تیتر خوب می‌افتد» | در فارسی بی‌معنی است؛ `text-transform` روی فارسی هیچ کاری نمی‌کند. خودِ تیتر کافی است. |
| «هر بخش یک fade-in بگیرد قشنگ می‌شود» | حرکتِ بی‌دلیل امضای کارِ ماشینی است. یک ورودِ سازمان‌یافته، بعدش سکوت. |

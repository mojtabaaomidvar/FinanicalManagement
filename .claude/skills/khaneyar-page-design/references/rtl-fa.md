# فارسی و راست‌به‌چپ

> این فایل مهم‌ترین بخشِ این اسکیل است. مراجعِ طراحیِ انگلیسی‌زبان **هیچ چیزی**
> دربارهٔ راست‌به‌چپ نمی‌گویند، و چند تا از قواعدِ سرفصلی‌شان برای فارسی
> فعالانه غلط است. اگر یک نصیحتِ طراحیِ انگلیسی با این فایل تناقض داشت،
> **این فایل برنده است.**

## پنج قاعده‌ای که از مراجعِ انگلیسی باید رد کنی

| نصیحتِ انگلیسی | برای فارسی |
|---|---|
| `letter-spacing: -0.02em` روی تیتر | **ممنوع.** حروفِ فارسی به هم می‌چسبند؛ فاصلهٔ منفی اتصال را خراب و «می‌شود» را ناخوانا می‌کند. مثبت هم بدتر است: کلمه از هم می‌پاشد. **صفر.** |
| `leading-none` / `line-height: 1.1` | **ممنوع.** زیر و زبَر (ـِ ـُ) و دنبالهٔ حروفی مثل ج چ ح خ ی پایین‌تر از خطِ کرسی می‌روند و به سطرِ بعد می‌خورند. کفِ مطلق ۱٫۳۵. |
| برچسبِ `ALL CAPS` بالای تیتر | فارسی حرفِ بزرگ ندارد؛ `text-transform:uppercase` روی فارسی **هیچ کاری نمی‌کند** و فقط رشتهٔ لاتینِ قِسِر‌رفته را جیغ می‌کند. |
| `<em>` / `font-style: italic` | فونت‌های فارسی italic ندارند؛ مرورگر آن را **مجازاً کج می‌کند** و نتیجه بد است. برای تأکید: `font-weight` یا `--green`. |
| `max-width: 65ch` | واحدِ `ch` روی فارسی بی‌معنی است (عرضِ «۰» معیار است). از `em` استفاده کن: **۴۴em** برای پاراگراف. |

## ارتفاعِ خط

```css
p, li      { line-height: 1.9;  }  /* بازهٔ مجاز ۱٫۸۵–۱٫۹۵ */
h1, h2, h3 { line-height: 1.45; }  /* بازهٔ مجاز ۱٫۴–۱٫۵ */
.tiny      { line-height: 1.75; }  /* ریزنوشت کمی بازتر از حسِ اول */
```

فارسی از لاتین **بازتر** نفس می‌کشد، نه بسته‌تر. اگر متنی شلوغ به نظر می‌رسد،
اول `line-height` را چک کن، بعد `font-size`.

## عدد و رشتهٔ لاتین درونِ متنِ فارسی

هر عدد یا نشانیِ لاتین که داخلِ جملهٔ فارسی می‌آید باید در یک ظرفِ LTR بنشیند،
وگرنه الگوریتمِ دوجهته پرانتز و نقطه و درصد را جابه‌جا می‌کند:

```html
<!-- غلط: نقطه و اسلش می‌پرند -->
<p>نسخهٔ 1.4.2 را از khaanehyar.ir/download بگیرید.</p>

<!-- درست -->
<p>نسخهٔ <span dir="ltr">1.4.2</span> را از
   <span dir="ltr">khaanehyar.ir/download</span> بگیرید.</p>
```

- عددِ فارسی در متنِ روان: **۳٫۳ مگابایت** (با ممیزِ فارسی `٫`)
- عددِ لاتین در جدول یا نشانی: داخلِ `dir="ltr"`
- `font-variant-numeric: tabular-nums` **فقط** داخلِ `dir="ltr"`؛ روی فارسی
  اثرِ درستی ندارد.
- یک صفحه یکی از دو دستگاهِ عددی را انتخاب کند. قاطی‌کردنِ «۳ کارت» و
  «3 کارت» در یک صفحه خودش را نشان می‌دهد.

## نشانه‌گذاری

```
گیومه:  «مثل این»   نه  "مثل این"
ویرگول: ،            نه  ,
سؤالی:  ؟            نه  ?
نقطه‌ویرگول: ؛
سه‌نقطه: …           نه  ...
نیم‌فاصله: می‌شود، خانه‌یار، صفحه‌ها   ← U+200C
```

نیم‌فاصله اختیاری نیست. «می شود» و «میشود» هر دو غلط‌اند.

## ویژگی‌های منطقی، نه فیزیکی

```css
/* غلط — در RTL برمی‌گردد */
padding-left: 16px;  margin-right: 8px;  text-align: left;
border-left: 1px solid;  left: 0;

/* درست */
padding-inline-start: var(--sp-4);  margin-inline-end: var(--sp-2);
text-align: start;  border-inline-start: 1px solid;  inset-inline-start: 0;
```

نگاشت: `left→inline-start` · `right→inline-end` · `top→block-start` ·
`bottom→block-end`. برای موقعیت: `inset-inline-start/end`,
`inset-block-start/end`.

**استثنا:** چیزی که ذاتاً فیزیکی است فیزیکی می‌ماند — سایه
(`box-shadow: 0 10px 30px`)، ماکاپِ گوشی که دکمه‌هایش جای واقعی دارند، و
هر چیزی که با `transform` جابه‌جا می‌شود.

## آیکونِ جهت‌دار

آیکونی که جهت دارد باید برگردد، آیکونی که ندارد نباید:

```css
/* برمی‌گردد: فلش، بازگشت، بعدی/قبلی، اشتراک‌گذاری، پاسخ */
.ic-arrow { transform: scaleX(-1); }
```

برنمی‌گردد: ساعت، تیک، آدم، قلب، ذره‌بین (دستهٔ ذره‌بین قرارداد جهانی است)،
لوگوی فروشگاه‌ها، و هر نشانِ برند.

در HTML، آیکونِ «بازگشت» در فارسی به **راست** اشاره می‌کند. اگر با
`padding-inline-start` چیده باشی، خودش سر جایش می‌رود.

## چیدمان

- `<html dir="rtl" lang="fa">` — هر دو، همیشه.
- ستونِ اول در چشمِ فارسی‌زبان **راست** است. با `flex` و `grid` این خودکار
  درست می‌شود؛ با `position` نه.
- `flex-direction: row` در RTL از راست می‌چیند. اگر لازم داری ترتیبِ بصری
  برعکسِ ترتیبِ DOM باشد، `order` بزن نه `row-reverse` — `row-reverse` در
  RTL معنایش عوض می‌شود و بعداً کسی نمی‌فهمد چرا.
- `scroll-snap` و کشوی افقی در RTL باید تست شود؛ `scrollLeft` منفی می‌شود.

## فونت

```css
--font-sans: "Vazirmatn", -apple-system, "SF Pro Text", "Segoe UI", sans-serif;
```

وزن‌های موجود و کاربردشان: ۴۰۰ متن · ۵۰۰ برچسب · ۶۰۰ تیترِ کارت ·
۷۰۰ تیترِ بخش · ۹۰۰ فقط `h1` و عددِ قهرمان. **وزنِ ۳۰۰ و پایین‌تر استفاده
نکن** — فارسیِ نازک روی نمایشگرِ معمولی محو می‌شود.

هیچ فونتِ مونویی برای فارسی نداریم. `<code>` فقط محتوای لاتین بگیرد و
`dir="ltr"` داشته باشد.

## چک‌لیستِ سریعِ متن

- [ ] `letter-spacing` روی هیچ متنِ فارسی‌ای نیست (نه منفی نه مثبت)
- [ ] هیچ `line-height` زیر ۱٫۳۵
- [ ] هیچ `uppercase` و هیچ `italic`
- [ ] هر رشتهٔ لاتین/عددِ لاتین در `dir="ltr"`
- [ ] گیومهٔ «» و ویرگولِ ، و علامتِ ؟
- [ ] نیم‌فاصله سرِ جایش
- [ ] هیچ `left`/`right`/`padding-left`ی که باید منطقی باشد
- [ ] پاراگراف زیرِ ۴۴em

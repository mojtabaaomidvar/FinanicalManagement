# بازبینی — دروازهٔ پیش از «تمام شد»

## قانونِ صفر

**بدونِ شاهدِ تازه، ادعای اتمام ممنوع.** «باید درست باشد»، «منطقاً کار
می‌کند»، «بعداً عکسش را می‌گیرم» هیچ‌کدام شاهد نیستند. شاهد یعنی یک فایلِ PNG
که همین الان ساخته شده و نگاهش کرده‌ای.

اگر عکس‌گرفتن نشد، دقیقاً همین را بگو — «نتوانستم عکس بگیرم، پس این را
بازبینی‌نشده تحویل می‌دهم» — و نگو تمام شد.

## عکس‌گرفتن

```bash
node tools/shot.cjs                # همهٔ صفحه‌ها × ۳۶۰ ۳۹۰ ۷۶۸ ۱۴۴۰
node tools/shot.cjs download       # فقط صفحهٔ دانلود، هر چهار عرض
node tools/shot.cjs download 360   # فقط دانلود، فقط موبایلِ کوچک
node tools/shot.cjs / 1440         # صفحهٔ اصلی، فقط دسکتاپ
```

خروجی: `_shots/<صفحه>-<عرض>x<ارتفاع>.png` — پوشه در `.gitignore` است.

**این اسکریپت روی ویندوز اجرا می‌شود، نه در VM.** مرورگرِ خودِ ویندوز
(Edge → Chrome) را می‌راند و چیزی دانلود نمی‌کند. بعد از اجرا، فایل‌ها را با
ابزارِ Read بخوان و **واقعاً نگاه کن**.

اگر اسکریپت هشدارِ `بارنشد:` یا `console:` چاپ کرد، آن‌ها را هم درست کن؛
یک فونتِ بارنشده در عکس معلوم نیست ولی روی گوشیِ کاربر معلوم است.

## ترتیبِ نگاه‌کردن

۳۶۰ را **اول** ببین، نه آخر. اگر در ۳۶۰ درست است، در ۱۴۴۰ هم تقریباً درست
است؛ برعکسش هیچ‌وقت. بیشترِ کاربرانِ این محصول روی گوشی‌اند.

## پانزده محورِ بازبینی

**چیدمان و فضا**
1. **ریتمِ فاصله** — فاصلهٔ بینِ بخش‌ها یکسان است؟ یا یکی ۶۴ و بعدی ۵۲ شده؟
2. **سلسله‌مراتب** — با یک نگاهِ نیم‌ثانیه‌ای، قهرمانِ صفحه کدام است؟ اگر
   جواب «نمی‌دانم» یا «دوتا» است، طرح شکست خورده.
3. **هم‌ترازی** — لبهٔ چپ‌وراستِ عناصر روی یک خطِ مشترک می‌نشیند؟
4. **تراکم** — جایی هست که هوا خالی مانده و جای دیگری خفه شده؟
5. **پاسخ‌گویی** — در ۳۶۰ چیزی سرریز یا برش خورده؟ کشویِ افقیِ ناخواسته؟

**تایپ**
6. **نردبان** — هر `font-size` از `--fs-*` آمده؟ عددِ خام مانده؟
7. **راست‌به‌چپ** — چک‌لیستِ پایینِ `rtl-fa.md` را رد کرده؟
8. **عرضِ سطر** — هیچ پاراگرافی از ۴۴em پهن‌تر نشده؟
9. **خوانایی در ۳۶۰** — ریزنوشت‌ها واقعاً خواندنی‌اند یا از سرِ ناچاری ریزند؟

**رنگ و سطح**
10. **یک تأکید** — فقط `--green` تأکید می‌کند؟ رنگِ تزئینیِ قاچاقی نیست؟
11. **کنتراست** — متن ۴٫۵:۱، آیکون و حاشیه ۳:۱. مشکوک‌ترین جا: `--text-3`
    روی `--card-2`.
12. **سایه یا حاشیه** — هیچ سطحی هر دو را ندارد؟

**تعامل و دسترس‌پذیری**
13. **هدفِ لمس** — هر چیزِ قابلِ‌زدن ≥ ۴۴×۴۴؟ با خط‌کشِ عکس اندازه بگیر.
14. **فوکوسِ کیبورد** — با Tab حلقه دیده می‌شود؟ `outline:none` بی‌جانشین
    جایی نیست؟
15. **حرکت** — انیمیشنِ بی‌دلیل هست؟ هر بخش fade-in خودش را دارد؟ (یعنی
    امضای کارِ ماشینی.) یک ورودِ سازمان‌یافته کافی است.

## شکلِ نوشتنِ یافته

هر ایراد در یک خط، سه‌قسمتی:

```
[بخش]: [چه غلط است] → [چه باید باشد] → [چرا مهم است]
```

مثال:

```
کارتِ دانلود ۳۶۰: دکمهٔ «دریافت» ۳۸ پیکسل بلند است → ۴۴ →
  زیرِ ۴۴ انگشت خطا می‌زند و کاربر دو بار می‌زند

تیترِ صفحه: letter-spacing: -0.6px روی متنِ فارسی → صفر →
  اتصالِ حروف را خراب می‌کند و «خودتان» شکسته دیده می‌شود
```

نه «شاید بهتر باشد یک نگاهی به فاصله‌ها بیندازیم». ایرادِ مبهم یعنی ایرادی
که درست نمی‌شود.

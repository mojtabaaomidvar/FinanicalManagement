# توکن‌ها — کدام عدد کجاست و چرا دو فایل CSS داریم

## دو فایل، دو دنیا

| فایل | مالِ کیست | خط‌پایان |
|---|---|---|
| `src/styles/style.css` | خودِ اپ (React، زیر `src/features/`) | **CRLF** |
| `site/assets/styles.css` | سایتِ معرفی (`site/index.html`, `site/download/`) | **LF** |

این دو عمداً جدا هستند: سایت هیچ بیلدی ندارد و باید بدونِ Vite هم درست باز
شود. **هیچ‌وقت یکی را وارد دیگری نکن.** اما پالت و شعاع و زمان باید یکی باشد،
وگرنه کاربر از سایت که وارد اپ می‌شود حس می‌کند دو محصول است.

> خط‌پایان را هنگام ویرایش حفظ کن. یک فایلِ CRLF که LF بشود، کلِ diff را
> عوض می‌کند و بازبینی را غیرممکن می‌کند.

## نردبانِ فاصله — `--sp-1..10`

```css
--sp-1:4px;  --sp-2:8px;   --sp-3:12px; --sp-4:16px; --sp-5:20px;
--sp-6:24px; --sp-7:32px;  --sp-8:44px; --sp-9:64px; --sp-10:96px;
```

`--sp-1..6` از قبل در `src/styles/style.css` هست. چهار پلهٔ بالا (`7..10`)
برای سایت لازم است، چون فاصلهٔ بینِ بخش‌ها در سایت بزرگ‌تر از اپ است.

**کاربرد:** ۱–۲ داخلِ یک جزء · ۳–۴ بینِ اجزای یک گروه · ۵–۶ padding کارت ·
۷–۸ بینِ گروه‌ها · ۹–۱۰ بینِ بخش‌های صفحه.

## نردبانِ تایپ — `--fs-1..7`

```css
--fs-1:11.5px; /* یادداشتِ زیرِ دکمه، ریزنوشت */
--fs-2:13px;   /* توضیحِ فرعی */
--fs-3:14px;   /* برچسب، متنِ کوتاه */
--fs-4:16px;   /* متنِ اصلی — پیش‌فرض */
--fs-5:18px;   /* لیدِ پاراگراف، تیترِ کارت */
--fs-6:21px;   /* h2 */
--fs-7:26px;   /* h3 بزرگ / عددِ شاخص */
```

`h1` تنها استثناست و `clamp()` می‌گیرد، چون باید با عرضِ صفحه نفس بکشد:

```css
h1 { font-size: clamp(28px, 4.4vw, 42px); }
```

### قاعدهٔ مهاجرتِ افزایشی

`site/assets/styles.css` همین حالا **بیست** اندازهٔ فونتِ متفاوت دارد:
۸٫۵ ۹٫۵ ۱۰ ۱۰٫۵ ۱۱ ۱۱٫۵ ۱۲ ۱۲٫۵ ۱۳ ۱۳٫۵ ۱۴ ۱۴٫۵ ۱۵ ۱۵٫۵ ۱۶ ۱۷ ۲۰ ۲۱ ۳۳ ۴۸.

**یک‌جا پاکشان نکن.** جارویِ کلِ فایل یعنی صد جای ندیده که ممکن است بشکند.
قاعده این است:

- بلوکِ **تازه** → فقط `var(--fs-*)`
- بلوکی که **داری دست می‌زنی** → همان‌جا به نزدیک‌ترین پلهٔ نردبان گِرد کن
- بلوکِ **دست‌نخورده** → رهایش کن؛ بعداً نوبتش می‌رسد

نگاشتِ گِردکردن: ۸٫۵/۹٫۵/۱۰/۱۰٫۵/۱۱ → `--fs-1` · ۱۱٫۵/۱۲/۱۲٫۵/۱۳ → `--fs-2`
· ۱۳٫۵/۱۴/۱۴٫۵ → `--fs-3` · ۱۵/۱۵٫۵/۱۶ → `--fs-4` · ۱۷/۱۸ → `--fs-5`
· ۲۰/۲۱ → `--fs-6` · ۲۶ → `--fs-7` · ۳۳/۴۸ → `clamp()`

## شعاع — سه‌تا، تمام

```css
--r-btn:8px;   /* دکمه، اینپوت، چیپ، آیکونِ کوچک */
--r-card:12px; /* کارت، شیت، مودال، جعبهٔ یادداشت */
--r-pill:999px;/* فقط قرص و آواتار */
```

در اپ `--r-sm`/`--r-md` = ۸ و `--r-lg`/`--r-xl` = ۱۲ همین دو عددند با نامِ
دیگر. **شعاعِ چهارم نساز.** اختلافِ ۸ و ۱۲ عمدی است: چیزِ تعاملی تیزتر،
ظرفِ محتوا نرم‌تر.

## حرکت

```css
--dur-fast:160ms; /* بازخوردِ لمس، hover، تغییرِ رنگ */
--dur-med:280ms;  /* بازشدن، ورودِ محتوا، تغییرِ حالت */
--ease-out:cubic-bezier(0.16,1,0.3,1);
--ease-spring:cubic-bezier(0.34,1.56,0.64,1); /* فقط جاهایی که «پرید» باید حس شود */
```

فقط `transform` و `opacity` را انیمیت کن. `height`، `width`، `top` و
`margin` هر فریم layout را بازمحاسبه می‌کنند و روی گوشیِ ارزان دیده می‌شود.

`prefers-reduced-motion` از قبل به‌صورت سراسری در `site/assets/styles.css`
هندل شده (`animation:none!important` + `transition:none!important`). پس
**لازم نیست** برای هر انیمیشنِ تازه یک media query جدا بنویسی.

## رنگ — پالتِ مشترک

```css
--navy:#0d1b2a;  --green:#10b981;  --green-strong:#059669;
--green-light:#22c55e; --mint:#34d399; --coral:#ff6b5b;
--bg:#f8f7f4;    --card:#ffffff;   --card-2:#edece7;  --surface:#e6f7f0;
--text:#0d1b2a;  --text-2:#4b5563; --text-3:#656d79;
--border:rgba(13,27,42,.09);  --border-strong:rgba(13,27,42,.18);
--income:#22c55e; --expense:#ef4444;
--shadow-sm:0 1px 2px rgba(13,27,42,.05);
--shadow-md:0 10px 30px rgba(13,27,42,.08);
--shadow-lg:0 24px 60px rgba(13,27,42,.16);
```

`--green` تنها رنگِ تأکید است. `--coral` فقط برای هشدار و «توجه»، نه برای
تنوعِ بصری. هشت جفتِ `--t-<hue>-fg/-bg` مالِ **برچسبِ دسته‌بندی‌ها** در اپ
است — از آن‌ها برای تزئینِ سایت استفاده نکن.

روی پس‌زمینهٔ navy: `--on-navy` `--on-navy-2` `--on-navy-3`.

## سایه یا حاشیه — یکی، نه هر دو

هر سطحِ برجسته **یا** حاشیه می‌گیرد **یا** سایه. با هم زدن، لبه را گِل‌آلود
می‌کند. پیش‌فرضِ این پروژه: کارت = `--border` + `--shadow-sm`. چیزی که واقعاً
روی صفحه شنا می‌کند (مودال، شیت) = فقط `--shadow-lg` بی‌حاشیه.

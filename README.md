# مالی من — مدیریت مالی خانواده (PWA)

اپلیکیشن وب مدیریت مالی خانواده، مختص موبایل (iPhone/Android)، فارسی و راست‌به‌چپ.
نسخه ۳.۰.۰ — داده‌ها روی **Supabase**، ورود با **شماره موبایل + رمز + کد پیامکی (OTP)**، دعوت اعضا با **لینک/QR**.

## ✨ امکانات

- 📱 **ورود دو مرحله‌ای** — شماره موبایل + رمز عبور، سپس کد تأیید ۶ رقمی پیامکی (SMS OTP)
- 📝 **ثبت‌نام ساده** — نام خانواده، نام شما، شماره موبایل و رمز عبور
- 🔗 **دعوت اعضا** — لینک دعوت یا **QR Code** برای اضافه کردن اعضای خانواده (از تنظیمات)
- 💳 **تراکنش‌ها** — ثبت/ویرایش/حذف درآمد و هزینه با ۱۴ دسته‌بندی
- 📅 **تقویم جلالی** — الگوریتم دقیق سال کبیسه (چرخه ۳۳ ساله)
- 📊 **گزارش‌ها** — نمودار حلقه‌ای، ستونی روزانه، روند ۶ ماهه (Canvas خالص)
- 📨 **پیامک بانکی** — چسباندن (Paste) متن پیامک واریز/برداشت؛ پارس خودکار بانک، مبلغ، موجودی و تاریخ
- 🔔 **پیامک‌های ثبت‌نشده** — هنگام باز شدن اپ، مودالی پیامک‌های رسیدگی‌نشده را یکی‌یکی برای ثبت نشان می‌دهد
- 🌙 تم تیره/روشن، بودجه ماهانه، خروجی JSON، نصب به‌عنوان اپ (PWA)

## 🚀 راه‌اندازی

### ۱) ساخت پروژه Supabase

1. به [supabase.com](https://supabase.com) بروید → **New Project**
2. نام و رمز دلخواه؛ منطقه (Region) را نزدیک انتخاب کنید (مثلاً Frankfurt)
3. پس از ساخت پروژه، به **SQL Editor** بروید
4. کل محتوای [`supabase/schema.sql`](supabase/schema.sql) را Paste و **Run** کنید
   - این اسکریما جدول‌های `otp_codes`، `family_invites` و `app_settings` را می‌سازد و ۹ تابع RPC امنیتی (ورود، ثبت‌نام، OTP، دعوت) تعریف می‌کند.

### ۲) تنظیمات اتصال

از **Settings → API** این دو مقدار را بردارید:

- **Project URL** — مثل `https://abcd1234.supabase.co`
- **anon public key** — کلید عمومی

سپس فایل [`js/config.js`](js/config.js) را ویرایش کنید:

```js
const SUPABASE_CONFIG = {
  url: "https://abcd1234.supabase.co", // ← Project URL شما
  anonKey: "eyJhbGciOi...", // ← anon key شما
};
```

### ۳) فعال‌سازی ارسال پیامک OTP

کد OTP از طریق تابع سرورلس [`api/send-otp.js`](api/send-otp.js) روی Vercel ارسال می‌شود. در داشبورد Vercel (پروژه → **Settings → Environment Variables**) این متغیرها را تنظیم کنید:

| متغیر                  | توضیح                                                       |
| ---------------------- | ----------------------------------------------------------- |
| `SUPABASE_URL`         | همان Project URL بالا                                       |
| `SUPABASE_SERVICE_KEY` | کلید `service_role` (از Settings → API — محرمانه، فقط سرور) |
| `SMS_PROVIDER`         | `kavenegar` یا `ghasedak` یا `smsir`                        |
| `KAVENEGAR_API_KEY`    | کلید سرویس کاوه‌نگار (در صورت انتخاب کاوه‌نگار)             |
| `GHASEDAK_API_KEY`     | کلید سرویس قاصدک (در صورت انتخاب قاصدک)                     |
| `SMSIR_API_KEY`        | کلید سرویس SMS.ir (در صورت انتخاب آن)                       |

> **حالت تست (بدون سرویس پیامک):** اگر `SMS_PROVIDER` تنظیم نشده باشد، تابع در حالت dev عمل می‌کند و کد را در پاسخ برمی‌گرداند تا در مرورگر نشان داده شود. همچنین اگر `app_settings.dev_mode` در دیتابیس `true` باشد، خود اپ هم کد موقت می‌سازد. **قبل از استفاده واقعی حتماً سرویس پیامک را وصل کنید و dev_mode را false کنید.**

### ۴) اجرای محلی

```bash
cd personal-finance-pwa
npx -y http-server -p 8090 -c-1
```

سپس در مرورگر: `http://localhost:8090`

> **نکته iOS:** برای نصب PWA روی آیفون، سایت باید **HTTPS** داشته باشد (مثل Vercel). روی localhost هم Service Worker کار می‌کند.

## 📤 ارسال به GitHub

### روش سریع — فایل bat (ویندوز)

فایل [`deploy.bat`](deploy.bat) را اجرا کنید (دابل‌کلیک). این فایل:

1. مخزن git می‌سازد (اگر نباشد) + فایل `.gitignore`
2. اگر هویت git تنظیم نشده باشد، نام و ایمیل می‌پرسد
3. commit می‌سازد و به GitHub پوش می‌کند (آدرس مخزن را می‌پرسد)
4. Vercel CLI را نصب می‌کند (اگر نباشد) و با `vercel --prod --yes` منتشر می‌کند

منوی ساده دارد: **[1] GitHub + Vercel** (پیش‌فرض) / **[2] فقط GitHub** / **[3] فقط Vercel**

می‌توانید آدرس مخزن را هم از قبل بدهید تا نپرسد:

```bat
deploy.bat https://github.com/USERNAME/REPO.git
```

> پیش‌نیازها: `git` و `Node.js` نصب باشد. برای GitHub احتمالاً یک‌بار `git config --global` یا login لازم باشد؛ برای Vercel اولین بار مرورگر برای ورود باز می‌شود.

### روش دستی

در پوشه پروژه:

```bash

git commit -m "مالی من — نسخه ۳ (ورود موبایل + OTP + دعوت QR)"
git branch -M main
git remote add origin https://github.com/mojtabaaomidvar/FinanicalManagement.git

```

> جای `USERNAME/REPO` نام کاربری و مخزن خودتان را بگذارید.
> اگر مخزن را از قبل در github.com ساخته‌اید (بدون README)، فقط دستورهای بالا را بزنید.

## 🌐 انتشار روی Vercel

### روش ۱ — از داشبورد (پیشنهادی)

1. به [vercel.com](https://vercel.com) بروید → **Sign up with GitHub**
2. **Add New → Project** → مخزن `personal-finance-pwa` را انتخاب کنید
3. تنظیمات را دست نزنید (استاتیک است، Build Command لازم ندارد؛ پوشه `api/` به‌صورت خودکار Serverless Function می‌شود) → **Deploy**
4. پس از چند ثانیه آدرس `https://your-app.vercel.app` آماده است
5. متغیرهای محیطی بخش «۳) فعال‌سازی ارسال پیامک OTP» را تنظیم و یک‌بار **Redeploy** کنید

### روش ۲ — با CLI

```bash
npm i -g vercel
cd personal-finance-pwa
vercel          # اولین بار: سوالات را Enter بزنید
vercel --prod   # انتشار نهایی
```

### نصب روی آیفون

آدرس Vercel را در Safari باز کنید → **Share ← Add to Home Screen** — اپ تمام‌صفحه با آیکون نصب می‌شود.

## 🔄 جریان کار اپ

1. **ثبت‌نام** — نام خانواده + نام شما + شماره موبایل + رمز عبور → کد ۶ رقمی پیامکی → ورود
2. **ورود** — شماره موبایل + رمز عبور → کد ۶ رقمی پیامکی → ورود (ورود دو مرحله‌ای)
3. **دعوت عضو** — تنظیمات → «دعوت عضو جدید» → **لینک** یا **QR Code** را برای عضو خانواده بفرستید
4. **پیوستن عضو** — عضو لینک را باز می‌کند (یا QR را اسکن می‌کند) → نام و رمز خودش را وارد می‌کند → کد پیامکی → عضو خانواده می‌شود
5. **ثبت تراکنش** — دکمه سبز پایین؛ نوع، مبلغ، دسته، عضو، تاریخ (جلالی)
6. **ورود پیامک** — آیکون پیامک در هدر داشبورد → متن را Paste کنید → پیش‌نمایش پارس → ذخیره
7. **پیامک‌های ثبت‌نشده** — در هر بار باز شدن اپ، مودال پیامک‌های pending را یکی‌یکی نشان می‌دهد: **ثبت** / **نادیده** / **بعداً**

## 🔐 نحوه کار ورود (خلاصه فنی)

- شماره موبایل به فرمت استاندارد `09xxxxxxxxx` نرمال می‌شود (+98 / 0098 / 98 هم پذیرفته می‌شود)
- رمز عبور با **SHA-256** (کلید = شماره موبایل) هش می‌شود و فقط هش در دیتابیس ذخیره می‌شود
- کد OTP: ۶ رقم، اعتبار ۵ دقیقه، حداکثر یک درخواست در ۶۰ ثانیه برای هر شماره
- توابع حساس (بررسی رمز، ساخت/بررسی OTP، ثبت‌نام، دعوت) به‌صورت **RPC با security definer** در Postgres اجرا می‌شوند و جداول حساس با RLS از دسترسی مستقیم محافظت می‌شوند
- لینک دعوت: توکن تصادفی ۴۰ کاراکری با اعتبار ۳۰ روز — هر خانواده یک دعوت فعال دارد

## 🗄 دیتابیس (Supabase)

| جدول             | توضیح                                                    |
| ---------------- | -------------------------------------------------------- |
| `families`       | خانواده‌ها + تنظیمات (بودجه، واحد، تم)                   |
| `members`        | اعضا — شماره موبایل یکتا + هش رمز + نقش (owner / member) |
| `transactions`   | تراکنش‌ها — تاریخ میلادی ذخیره، جلالی نمایش              |
| `sms_messages`   | پیامک‌های بانکی — وضعیت: pending / recorded / ignored    |
| `otp_codes`      | کدهای یک‌بار مصرف ورود — انقضا ۵ دقیقه                   |
| `family_invites` | دعوت‌نامه‌ها — توکن + خانواده + اعتبار ۳۰ روز            |
| `app_settings`   | تنظیمات سراسری — مثل `dev_mode` (حالت تست بدون پیامک)    |

> **امنیت:** منطق حساس داخل توابع RPC با `security definer` است و RLS روی جداول حساس فعال است. کلید `service_role` فقط در متغیرهای محیطی Vercel نگه داشته می‌شود و هرگز به کلاینت نمی‌رسد.

## 🛠 تکنولوژی

- HTML/CSS/JS خالص — بدون فریم‌ورک، بدون بیلد
- Supabase PostgREST (fetch خالص، بدون SDK) + توابع Postgres
- Vercel Serverless Functions (Node.js) برای ارسال پیامک
- qrcode-generator برای ساخت QR روی Canvas
- Canvas 2D با پشتیبانی Retina (DPR)
- Vazirmatn (فونت فارسی) + iOS HIG الگوهای طراحی

# خانه‌یار 0.8.0 — کتابخانهٔ غذا و دفتر آشپزخانه

این انتشار با تأیید کاربر پس از بررسی نسخهٔ آزمایشی و اصلاح عرض موبایل آماده
می‌شود. مبنا نسخهٔ رسمی `v0.7.2` است؛ تغییرهای غذا از شاخهٔ مستقل تست منتقل
شده‌اند تا قابلیت دستیار خانه و اصلاحات رسمی `0.7.0–0.7.2` حفظ شوند. شاخهٔ
انتشار `codex/release-0.8.0` است. workspace اصلی و داده‌های تست دستی تغییری نمی‌کنند.

## محدوده

- کتابخانهٔ ۴٬۵۸۳ غذا با ۵٬۸۳۲ ترکیب مستقل مواد، ده برچسب وعده و پنجاه دستهٔ
  منبع. فقط نام مواد ارائه می‌شود؛ مقدار، روش پخت یا دسته‌بندی تازه‌ای حدس زده نمی‌شود.
- برنامهٔ روزانهٔ صبحانه، ناهار و شام، انتخاب هفت‌روزه، نمای کامل هفته و انتخابگر
  جست‌وجوشوندهٔ غذا. کتابخانه و غذاهای خانواده جدا می‌مانند.
- طراحی دفتر آشپزخانه، تصویرهای خطی محلی، فارسی راست‌به‌چپ و تم روشن/تیره؛ ستون
  استاندارد ۵۲۰ پیکسل و پنجرهٔ استاندارد ۵۵۲ پیکسل در نمایشگر بزرگ، با کاهش عرض
  مطابق گوشی. کتابخانه و نمای هفته تک‌ستونه‌اند.
- ذخیرهٔ صریح یک ترکیب بررسی‌شده در غذاهای خانواده؛ مقدار نامشخص `null` می‌ماند.
  مقدارهای عددی قبلی، مجوز سازنده/مدیر، بازبینی‌ها و خرید قبلی حفظ می‌شوند.
- سازگاری با دستیار رسمی خانه: مواد بدون مقدار وضعیت نامشخص دارند و باعث خطای
  تبدیل عدد یا مقدار حدسی نمی‌شوند. قرارداد پاسخ HTTP و سرویس خصوصی تغییر نمی‌کند.

دادهٔ عمومی در شاخص جست‌وجو و ۲۵۶ بخش جزئیات بارگیری می‌شود؛ JSON کتابخانه وارد
پیش‌کش پوستهٔ PWA نمی‌شود. نوشته‌های ثابت رابط در ویرایشگر محلی قابل‌ویرایش‌اند؛
نام‌های غذا، مواد، دسته‌های منبع و دادهٔ کاربر جدا و محافظت‌شده می‌مانند.

## نصب و حفظ اطلاعات

ارتقای نصب‌کننده فقط از API و PWA تطبیق‌یافتهٔ رسمی `v0.7.2` یا تکرار کامل همین
نسخه پذیرفته می‌شود. revision دیتابیس `0034_assistant_receipts` باقی می‌ماند؛
مهاجرت، backfill، downgrade و بازیابی خودکار دیتابیس اجرا نمی‌شود.

`backend/deploy/install-meals-release.sh` پیش از تغییر، هش API، مهاجرت‌های موجود،
فایل‌های راه‌اندازی، PWA و همهٔ بخش‌های کتابخانه را بررسی می‌کند. نقش API محدود،
RLS، تریگر موجودی، کلید رمزنگاری و اتصال خصوصی فعلی دستیار نیز بررسی می‌شوند.
پیش از تعویض کد، پشتیبان یکپارچهٔ دیتابیس، آپلودها، تنظیمات و PWA گرفته می‌شود.
در شکست، فقط API/schema قبلیِ بررسی‌شده بازگردانده می‌شود؛ حالت نامطمئن با حفظ
پشتیبان خاموش می‌ماند. فایل‌های ناشناختهٔ سرور خودکار حذف یا بازنویسی نمی‌شوند.

سرویس خصوصی هوش مصنوعی و nginx آن در این نصب تغییر نمی‌کنند و تحلیل هزینه‌دار
اجرا نمی‌شود. کلیدها، تنظیمات پشتیبانی، اطلاعات واقعی، آپلودها و APK حفظ می‌شوند؛
نسخهٔ تازهٔ اندروید ساخته نشده است.

## اعتبارسنجی و وضعیت انتشار

نتایج نسخهٔ تست در [گزارش غذا](meals-test-2026-11-23.md) ثبت شده‌اند. آزمون‌های
منبع دقیق این انتشار، ساخت رسمی، تطبیق با مبنا، بررسی بسته و نصب‌کننده و نتایج
PostgreSQL مستقل در `validation.json` بسته ثبت می‌شوند. آزمون‌های دستیار از
پاسخ HTTP و parser واقعی عبور می‌کنند؛ فقط سرویس بیرونی ساختگی است و دادهٔ واقعی
یا درخواست هزینه‌دار استفاده نمی‌شود. ادعای اجرای کل مجموعهٔ بک‌اند نداریم.

بررسی‌های تکمیل‌شدهٔ منبع انتشار: ۷۳۴ آزمون فرانت‌اند در ۸۹ فایل، ۱۲۸ آزمون
ویرایشگر نوشته‌ها، ۴٬۹۷۳ متن قابل‌ویرایش، TypeScript و ساخت رسمی، پنج آزمون
پروجکشن و تطبیق بازتولید همهٔ فایل‌های کتابخانه با منبع تأییدشده، سیزده بررسی
نصب‌کننده و چهارده مسیر دستیار در مرورگر. مجموعهٔ غذا در Chrome و Firefox، نماهای
روز/هفته/کتابخانه/جزئیات را در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۳۰، ۷۶۸ و ۱۴۴۰ پیکسل
بررسی کرد؛ اجرای نهایی هر دو بدون خطای صفحه پاس شد. بررسی picker نوشته‌ها نیز
بدون تغییر منبع پاس شد. اجرای نخست Firefox پیش از شروع بررسی‌ها در ورود به
fixture timeout داشت؛ نتیجهٔ آن نگه داشته شد و اجرای مجدد مستقل پاس شد.

بازاجرای نهایی ۵۵۵ آزمون مرتبط بک‌اند و gateway در PostgreSQL موقت بدون شکست،
خطا یا آزمون ردشده پاس شد. شش مورد تازه، مقدار نامشخص را با موجودی صفر یا مثبت
در تابع وضعیت مواد و مسیر HTTP واقعی دستیار بررسی می‌کنند. در اجرای نخست دو
assertion تازه صرفاً به علت مقایسهٔ رشتهٔ `20` با خروجی معتبر `20.00` شکست خورد؛
مقایسه به مقدار Decimal اصلاح شد، رفتار برنامه تغییر نکرد و کل محدوده مجدداً
اجرا شد. گزارش اولیه برای شفافیت نگه داشته شده است.

انتشار GitHub و نصب سرور دو مرحلهٔ جدا هستند. نصب در VNC با `install.sh` انجام
می‌شود؛ تا دریافت خروجی موفق و بررسی `https://pwa.khaanehyar.ir/version.json`،
نصب این نسخه تأییدشده نیست.

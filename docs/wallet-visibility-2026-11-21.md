# نمایش کیف پول‌ها — ۲۱ نوامبر ۲۰۲۶

درخواست کاربر: در بخش مالی، صفحهٔ کاشی «کیف پول» برای عضو عادی فقط حساب‌ها و کیف پول‌های خودش را نشان دهد؛ مالک (`owner`) و مدیر (`admin`) حساب‌های همهٔ اعضای خانوادهٔ جاری را ببینند. ریدیزاین اساسی انبار و لیست خرید تا ارائهٔ جزئیات بعدی کاربر به تعویق افتاده است.

محدودهٔ نمایش در مدل مشترک حساب‌ها اعمال شده، بنابراین صفحهٔ کیف پول و زیرصفحهٔ حساب‌های تنظیمات یکسان‌اند. فهرست، جمع دارایی و نمودار نقد از همان حساب‌های مجاز استفاده می‌کنند. دارایی‌های بازاری هم به مالکیت عضو محدود می‌شوند. تراکنش‌ها با حساب مبدأ و مقصد محاسبه می‌شوند تا انتقال ورودی از عضو دیگر حذف نشود. نبود هویت بیننده، فهرست خالی می‌دهد؛ تغییر نقش، محدودهٔ نمایش را دوباره محاسبه می‌کند.

این تغییر مربوط به نمایش کیف پول است. دادهٔ مشترک حساب‌ها و قرارداد API خانواده برای مسیرهای دیگر، از جمله انتخاب مقصد انتقال، حفظ شده‌اند. مجوز ویرایش حساب‌ها تغییری نکرده است.

اعتبارسنجی:

- ۴۰ آزمون مربوط به نمایش کیف پول، انتخاب حساب تراکنش و قواعد گزارش پاس شدند.
- TypeScript، ساخت PWA و `copy:studio:coverage` پاس شدند؛ متن‌های شخصی صفحه در ویرایشگر متن استخراج می‌شوند.
- فایرفاکس در عرض موبایل، فهرست و جمع دارایی عضو، مالک و مدیر را بررسی کرد. تزریق حساب و دارایی عضو دیگر نیز وارد نمایش یا جمع شخصی نشد.
- خروجی مرورگر در `.local-test/wallet-visibility/` ذخیره شده است.
- `npm run sandbox:refresh` موفق بود؛ نسخهٔ تست دستی روی `http://127.0.0.1:5700` به‌روز شد و دیتابیس و فایل‌های دستی حفظ شدند.

تغییر روی سرویس اصلی منتشر نشده است.

تغییرها شامل ثبت اتمی کارمزد انتقال از حساب مبدأ، محاسبهٔ صحیح ریالی در سرویس مشترک، حفظ هزینه‌های قبلی تکرار، پیشنهاد نام و حساب خود عضو از متن پیامک، نگهداری رقم آخر ریال در ذخیره و نمایش موجودی، چسبیدن هدر اعلان‌ها به بالا و نزدیک شدن نشانگرهای قابل لمس به بیلبورد هستند. پایای گروهی در فرم قرار ندارد. جزئیات قرارداد در `docs/transfer-fees-2026-11-19.md` آمده است.

۶۵۵ تست فرانت‌اند، ۱۱۵ تست ویرایشگر متن، ۱۱۷ تست مرتبط بک‌اند روی PostgreSQL جدا، ۱۸ بررسی مالی مرورگر، ۱۸ بررسی پیامک، ۸ بررسی کارمزد/ریال/پیشنهاد حساب و ۳ صفحهٔ پیش‌نمایش موفق شدند. سه تست تنظیمات نصب‌کننده نیز پاس شدند. ۴۲۶۰ نوشتهٔ نمایشی پوشش دارند و واژگان داخلی parser قابل ویرایش نیستند. ساخت رسمی صریحاً به `https://api.khaanehyar.ir` متصل است و بستهٔ ۱۴ فایل PWA فاقد اتصال محلی یا instrumentation پیش‌نمایش است.

محیط دستی ۵۷۰۰ از طریق راه‌اندازهای خودش تازه و به revision `0026` مهاجرت داده شد. نمونه‌های خواندنی پیش و پس از ارتقا، با نرمال‌سازی scale موجودی و حذف ستون‌های تازهٔ null از مقایسه، حفظ حساب‌ها، تراکنش‌ها، پیامک‌ها، اعضا و هش آپلودها را تأیید می‌کنند. API محیط دستی ۴ حساب، ۹ تراکنش و پاسخ صحیح کارمزد را برگرداند.

## وضعیت نصب سرور

نصب r2 روی سرور اصلی هنوز انجام نشده است. بررسی خواندنی پیش از نصب روی سرور `193.138.77.239` با revision `0025` موفق بود، اما اتصال SSH روی پورت ۲۲ بعداً به‌طور مکرر timeout شد. پورت‌های HTTP و HTTPS و برنامه/API اصلی پاسخ می‌دهند. کاربر تأیید کرده است پورت ۲۲ باید فعال باشد. هیچ مرحلهٔ نصب روی سرور آغاز نشده؛ آخرین نسخهٔ نصب و تأییدشدهٔ سرور همان r1 است.

پس از بازگشت دسترسی SSH، نصب‌کنندهٔ همین بسته باید با بکاپ و حفظ کلیدها، داده‌ها و RLS اجرا شود؛ سپس هش ۱۴ فایل عمومی، تصویر و شش فایل بک‌اند، revision `0026` و نمونهٔ داده‌های پس از نصب با نمونهٔ قبل مقایسه شوند. نرخ‌ها و محدودیت کانال تازه‌ای بدون تعرفهٔ معتبر اضافه نشده‌اند. وضعیت `installed_on_server:false` در manifest با وضعیت فعلی نصب سازگار است.

برای اجرای همان نصب‌کننده از کنسول root خود سرور:

```bash
curl -fL https://github.com/mojtabaaomidvar/FinanicalManagement/releases/download/finance-2026-11-19-r2/install.sh -o /tmp/khaneyar-r2-install.sh
bash /tmp/khaneyar-r2-install.sh
```

نصب‌کننده هش آرشیو را پیش از استخراج کنترل می‌کند و از PyPI اصلی برای وابستگی‌ها استفاده می‌کند. نصب کنسولی نیز به تأیید مستقل پس از نصب نیاز دارد.

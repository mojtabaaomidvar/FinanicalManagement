# داشبورد مدیریت 0.2.0 — ۲۵ نوامبر ۲۰۲۶

این انتشار مستقل با تگ `management-v0.2.0` برای به‌روزرسانی پنل مدیریت نصب‌شدهٔ `0.1.0` آماده می‌شود. صفحهٔ نخست داشبورد است: چهار شاخص کلی، نمودار خانواده و تکمیل ثبت‌نام، نمودار درخواست موفق و بازشدن و خطاهای ورود، رتبه‌بندی شش بخش پرکاربرد و ترکیب وضعیت حساب‌ها، همراه با آخرین وضعیت API، PostgreSQL، وب‌سرور و منابع میزبان.

نمودارها از گزارش تجمیعی موجود استفاده می‌کنند. درخواست، فرد یکتا محسوب نمی‌شود و بار پردازنده درصد مصرف نیست. دادهٔ ناموجود صفر فرض نمی‌شود؛ در نمودار شکاف می‌گذارد و جمع ناقص نمایش داده نمی‌شود. نمودار با اشاره، لمس، انتخاب شاخص و بازه و نوار انتخاب روز با صفحه‌کلید قابل بررسی است و جدول اعداد نیز دارد. محور شمارش از صفر است و تاریخ‌ها شمسی به وقت تهران هستند. گزارش کامل قبلی و همهٔ کنترل‌های عملیاتی حفظ شده‌اند.

به‌روزرسانی فقط رابط وب را تغییر می‌دهد. کد اجرایی بک‌اند مدیریت و قرارداد API با `0.1.0` یکسان‌اند. نصب‌کنندهٔ تازه، هش فایل‌ها و نسخهٔ سازگار نصب‌شده را بررسی و رابط قبلی را حفظ می‌کند؛ در شکست بررسی سلامت، رابط قبلی بازمی‌گردد. رمز و کلید دومرحله‌ای و نشست‌ها تغییر نمی‌کنند. API و PWA خانوادگی، دیتابیس، nginx و sudoers تغییر نمی‌کنند و هیچ سرویسی restart نمی‌شود. فایل‌های asset قبلی برای تب‌های باز نگه داشته می‌شوند. نصب به root از کنسول VNC نیاز دارد.

شمار تست‌ها، بررسی مرورگر و هش فایل‌ها در `validation.json` انتشار ثبت می‌شوند. تست نصب‌کننده روی پوشهٔ واقعی موقت، جابه‌جایی موفق، اجرای مجدد، شکست بررسی سلامت و حفظ هویت، تغییر دستی و manifest نامعتبر را پوشش می‌دهد. تست عملیات root واقعی و نصب سرور در این جلسه انجام نمی‌شود. انتشار بسته به معنی نصب نیست؛ پس از نصب، `/management/version.json` باید `0.2.0` را گزارش کند.

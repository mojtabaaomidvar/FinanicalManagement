# پنل مدیریت مستقل 0.1.0 — ۲۵ نوامبر ۲۰۲۶

این انتشار با تگ مستقل `management-v0.1.0`، پنل مدیریت سرور و نرم‌افزار و گزارش آمار تجمیعی را فراهم می‌کند. منبع آن از نسخهٔ رسمی `v0.11.0` و فقط فایل‌های مدیریت ساخته شده است. شماره و فایل‌های اجرایی برنامهٔ خانوادگی، مهاجرت‌های پایگاه داده، پنل پشتیبانی و درگاه هوش مصنوعی در این انتشار ارتقا نمی‌یابند.

نشانی مدیریت پس از نصب `https://supp.khaanehyar.ir/management/` است. ریشهٔ دامنه، پنل پشتیبانی فعلی را نمایش می‌دهد. نصب روی میزبان nginx موجود انجام می‌شود؛ کانفیگ شناخته‌شده و گواهی همین دامنه باید از قبل فعال باشند. مسیر متداخل، لینک ناشناخته و نصب قبلی مدیریت پیش از تغییر رد می‌شوند. کانفیگ پشتیبانی قبل از افزودن مسیر جدید پشتیبان‌گیری می‌شود و شکست اعتبارسنجی nginx آن را بازمی‌گرداند.

بسته با دستور `install.sh` از کنسول VNC و با کاربر root نصب می‌شود. راه‌انداز هش SHA-256 آرشیو را پیش از استخراج بررسی می‌کند. نصب‌کننده محیط Python مستقل، سرویس systemd با کاربر محدود، worker متعلق به root، sudoers محدود و پایگاه هویت خصوصی می‌سازد. رمز مالک `admin` در کنسول دریافت و کلید دومرحله‌ای برای ثبت در برنامهٔ رمزساز فقط همان‌جا نمایش داده می‌شود. رمز اپراتور پشتیبانی و دادهٔ محیط محلی استفاده نمی‌شوند. timer پشتیبان روزانه ابتدا خاموش است.

پنل وضعیت واقعی API، PostgreSQL و منابع میزبان را می‌خواند. گزارش محصول فقط شمارنده‌ها و تعداد کل رکوردها را دارد؛ نام، شماره، شناسهٔ عضو یا خانواده، مبلغ، متن پیامک، محتوای سند و اطلاعات دستگاه در گزارش و خروجی آن قرار نمی‌گیرند. گزارش روزانه با وقت تهران و بازه‌های ۷، ۳۰ و ۹۰ روز ارائه می‌شود. دادهٔ ناموجود با صفر جایگزین نمی‌شود. گزارش بازدید سایت معرفی، کاربران فعال یکتا، بازگشت کاربران و زمان استفاده فعلاً اندازه‌گیری نشده است.

کلیدهای تعمیرات، ثبت‌نام و دستیار به middleware و mount زمان اجرای API سازگار نیاز دارند. تا وقتی API جاری اتصال `managed_runtime: v1` را گزارش نکند این سه کنترل غیرفعال می‌مانند. نصب مدیریت به‌تنهایی API یا PWA را بازسازی یا restart نمی‌کند و مهاجرت دیتابیس ندارد؛ عملیات بعدی مدیر در پنل، مطابق پیش‌نمایش و تأیید همان عملیات انجام می‌شود.

گزارش ساخت، تعداد تست‌ها، وضعیت مرورگر و هش فایل‌های بسته در `validation.json` و `SHA256SUMS` همین انتشار قرار دارند. اعتبارسنجی محلی از PostgreSQL موقت و مستقل و سرویس مرورگر جدا استفاده می‌کند. آزمون نصب واقعی Linux و عملیات root روی سرور از این رایانه انجام نشده است؛ انتشار بسته به معنی نصب آن نیست. نشانی عمومی نسخه پس از نصب `/management/version.json` است و نشست ناشناس باید حالت `production` داشته باشد.

# نام و آیکون نصب پنل پشتیبانی

دامنهٔ پشتیبانی ورودی `support.html` و manifest مستقل `support.webmanifest` را ارائه می‌کند. نام کامل و کوتاه نصب «پشتیبانی» است؛ عنوان صفحه و عنوان نصب iOS نیز همین نام را دارند. آیکون هدست و حباب گفت‌وگو از SVG مستقل ساخته شده و PNGهای ۱۹۲، ۵۱۲ و ۵۱۲ مناسب برش سیستم‌عامل دارد. دکمهٔ برگشت از ورود و همهٔ بخش‌های پنل حذف شده است.

شناسه، دامنهٔ شروع و محدودهٔ نصب همچنان ریشهٔ همان میزبان هستند؛ تغییر نوشته یا آیکون، هویت نصب را به نام وابسته نمی‌کند. ورودی، manifest و آیکون‌های برنامهٔ خانوادگی جدا باقی می‌مانند. HTML پشتیبانی تنها manifest خودش را دارد و اسکریپت ثبت کارگر پس‌زمینه در آن درج نمی‌شود؛ مسدودبودن کارگر روی nginx نیز حفظ شده است.

نام نصب، توضیح و عنوان از `src/features/support/branding.ts` گرفته می‌شوند. هر نوشته شناسهٔ پایدار `@copy-text` دارد؛ شناسهٔ قبلی `support.page_title` هنگام جابه‌جایی حفظ شده است. جایگزینی هنگام ساخت فقط روی جایگاه‌های فنی HTML پشتیبانی و با escape متن انجام می‌شود؛ دادهٔ کاربر در آن مسیر نیست. نوشته‌های عادی برند و برچسب تصویر در JSX همچنان مستقل و قابل انتخاب در ویرایشگرند.

ساخت تولید، TypeScript، ۶۵۹ تست برنامه، ۱۱۷ تست ویرایشگر و پوشش متن‌ها بررسی می‌شوند. بررسی Firefox با داده‌های ساختگی، نام و آیکون نصب، نبود برگشت در چهار بخش و ورود، عرض واقعی ۳۹۰ پیکسل و هویت منبع نوشته پس از پیش‌نویس انگلیسی و خالی را پوشش می‌دهد. در این اجرا ویندوز پورت‌های ۵۷۰۰ تا ۵۸۰۰ را رزرو کرده بود؛ بررسی مرورگر روی پورت‌های آزاد و بدون اتصال به API تولید انجام شد. سازگارسازی پورت پیش‌نمایش فقط در ابزار خصوصی تست انجام شد و کد اصلی نگهبان پورت تغییر نکرد.

نصب نسخهٔ تازه همچنان به‌صورت دستی توسط کاربر در VNC انجام می‌شود. برای میانبرهای قدیمی گوشی، به‌خصوص iOS، ممکن است لازم باشد میانبر پنل دوباره به صفحهٔ اصلی اضافه شود تا نام و آیکون تازه نمایش داده شوند.

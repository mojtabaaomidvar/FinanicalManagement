# انتشار خانه و کیف‌پول‌ها — ۱۹ نوامبر ۲۰۲۶

نسخهٔ `finance-2026-11-19` روی [PWA اصلی](https://pwa.khaanehyar.ir) و [API اصلی](https://api.khaanehyar.ir) نصب و مستقلاً تأیید شد. منبع بسته commit `5d911e54f0dff1314192b7a6b1ca8fc2a1d9fea3` روی شاخهٔ `codex/finance-home-2026-11-19` است. بسته و گزارش نهایی در [انتشار GitHub](https://github.com/mojtabaaomidvar/FinanicalManagement/releases/tag/finance-2026-11-19) قرار دارند.

بیلبورد چهار کارت تصویری با حرکت لایه‌ای، محوشدگی متناسب با کشیدن و نمایش خودکار دارد. تب‌های متن‌دار زیر آن حذف شده‌اند. نوار پایین «داشبورد، بخش‌های خانه، اعلان‌ها» است. صفحهٔ بخش‌ها تمام ماژول‌ها را در چهار دستهٔ باز با کاشی‌های کوتاه نشان می‌دهد. دستگیره‌های شش‌نقطه‌ای حذف شده و پین‌های شخصی حفظ می‌شوند. اعلان بالای صفحهٔ مالی نیز حذف شده است.

حساب بانکی و کیف‌پول نقدی یک فهرست مشترک دارند. درآمد موجودی‌های صفر را هم نشان می‌دهد؛ هزینه و مبدأ انتقال حساب کم‌موجودی برای مبلغ واردشده را حتی پس از «نمایش همه» پنهان می‌کنند. نسخه، فهرست بانک‌های به‌روز، محافظت مالکیت و حذف حساب، ویرایش برنامهٔ تکرار و تسویهٔ یکتای نوبت آینده را هم شامل می‌شود.

## اعتبارسنجی

۶۴۳ تست فرانت‌اند، ۱۱۴ تست ویرایشگر متن، ۸۷۳ تست بک‌اند روی PostgreSQL جدا، ۱۷ بررسی مرورگر مالی و ۱۴ بررسی پیامک بانکی موفق شدند. یک xfail و یک xpass شناخته‌شده در مجموعهٔ بک‌اند باقی‌اند. پوشش ۴۱۷۶ نوشتهٔ قابل‌ویرایش، TypeScript و ساخت رسمی PWA موفق‌اند. هشدار شناخته‌شدهٔ اندازهٔ bundle باقی است.

بررسی مرورگر روی دادهٔ ساختگی پورت ۵۷۰۱ انجام شد. نسخهٔ دستی ۵۷۰۰ نیز با حفظ حساب‌ها، تراکنش‌ها و هش فایل‌ها تازه شد؛ هیچ دیتابیس، آپلود، نشست، تنظیمات خصوصی، نمونهٔ طراحی یا پوشهٔ شخصی محلی وارد بسته نشده است. چهار فایل شل آرشیو، LF برچسب و پیش‌شرط اجرای نصب‌کننده بررسی شدند. هر چهار فایل قابل دریافت انتشار با SHA-256 محلی تطبیق داشتند.

## نصب و تأیید سرور

نصب از SSH و با آرشیو دارای SHA-256 تأییدشده انجام شد. نصب‌کننده قبل از توقف API تصویر را ساخت، از دیتابیس و آپلودها و تنظیمات بکاپ گرفت و مهاجرت افزایشی `0024 → 0025` را اجرا کرد. پیام `RELEASE INSTALLED: finance-2026-11-19` و شروع API تأیید شدند.

بکاپ: `/var/backups/khaneyar/releases/20261119-161035`. منبع فعال: `/opt/khaneyar-release.NJoIzO/source`. این مسیر برای ساخت‌های بعدی حفظ شود. تصویر فعال API: `khaneyar-api:finance-2026-11-19`.

مقایسهٔ خواندنی قبل و بعد، حفظ کامل حساب‌ها، تراکنش‌های قبلی، هش آپلودها، کلید رمزنگاری، تنظیمات امضا و RLS/FORCE RLS را تأیید کرد. revision دیتابیس `0025` است. هر ۱۴ فایل عمومی PWA پاسخ ۲۰۰ داشت و SHA-256 آن‌ها دقیقاً با بسته برابر بود؛ تنظیمات احراز هویت پاسخ ۲۰۰ و چهار مسیر مالی بدون نشست پاسخ ۴۰۱ دادند. مرورگر موبایل عمومی بدون خطای JavaScript و بدون نوشتن به API نسخهٔ تازه را باز کرد. هیچ حساب، نشست یا داده‌ای در تولید ساخته نشد.

خطاهای موقت curl در حلقهٔ آمادگی کانتینر رخ دادند؛ نصب پس از پاسخ موفق ادامه یافت. مقدار `installed_on_server:false` داخل manifest وضعیت زمان بسته‌بندی است؛ گزارش `server-verification.json` نتیجهٔ بعد از نصب را ثبت می‌کند. APK تازه لازم نیست؛ برنامهٔ نصب‌شده از PWA اصلی استفاده می‌کند و به‌روزرسانی آن باید پذیرفته شود.

# خانه‌یار 0.9.0 — ثبت مالی، پیامک و پرداخت آنلاین

کاربر انتشار روی GitHub را تأیید کرده است. این اجازه شامل نصب روی سرور، گوشی یا تغییر داده‌های واقعی نیست. مبنا نسخهٔ رسمی `v0.8.0` با کامیت `e325d9e0debd5ea8edbf7f29a10ed705d15a0fd3` است؛ شاخهٔ کار `codex/finance-integrity` باقی می‌ماند.

## تغییرها

- ثبت همهٔ دسته‌های معتبر هزینه و درآمد، از جمله تاکسی اینترنتی؛ حفظ دسته‌های تاریخی هنگام ویرایش.
- اصلاح تشخیص بانک، جداسازی متن خام و اطلاعات دریافت پیامک از یادداشت کاربر، و حفظ تاریخ و ساعت واقعی تراکنش. تاریخ نامعلوم یا مبهم نیازمند بازبینی است.
- ثبت اتمی پیامک، تراکنش و کارمزد؛ جلوگیری از ثبت مالی دوباره هنگام تکرار درخواست یا استفادهٔ هم‌زمان از دو دستگاه. سوابق نامطمئن قدیمی به بازبینی ارجاع می‌شوند.
- حذف مسیرهای دستیار هوش مصنوعی از ثبت مالی؛ دستیار غیرمالی خانه حفظ می‌شود.
- ذخیرهٔ روش پرداخت: کارت، پرداخت آنلاین یا انتقال بانکی. کارت و پرداخت آنلاین کارمزد انتقال ندارند.
- نمایش کارمزد پیوندخورده زیر پرداخت اصلی، فیلتر کارمزد و مجموع آن بدون دوباره‌شماری. کارمزد به حساب مبدأ نسبت داده می‌شود. کارمزد تاریخیِ بدون والد برای حفظ اطلاعات همچنان دیده می‌شود.

## نصب‌کنندهٔ محدود

بسته فقط API و PWA را ارتقا می‌دهد؛ APK تازه، درگاه هوش مصنوعی، تنظیمات پشتیبانی، nginx و سایت معرفی را تغییر نمی‌دهد. اصلاح انتقال اطلاعات دریافت پیامک اندروید در سورس هست، ولی انتشار APK و آزمایش دریافت واقعی روی دستگاه جداست.

`backend/deploy/install-finance-release.sh` پیش از توقف API، هش‌های سورس، مهاجرت‌ها و PWA نصب‌شده را با نسخهٔ رسمی مقایسه می‌کند. از PWA و تنظیمات پشتیبان می‌گیرد، سپس API را برای پشتیبان سازگار دیتابیس و آپلودها متوقف می‌کند. تنها مهاجرت‌های `0035_sms_integrity` و `0036_payment_method` با هم و در یک تراکنش اجرا می‌شوند. ستون‌های جدید nullable هستند؛ هیچ سابقه‌ای پاک، بازنویسی یا تکمیل حدسی نمی‌شود.

مهاجرت محدود، اثر انگشت همهٔ جدول‌های تاریخی را قبل و بعد مقایسه می‌کند و خالی‌ماندن ستون‌های جدید در ردیف‌های قدیمی را بررسی می‌کند. خطای بررسی یا محدودیت زمان باعث rollback همان تراکنش می‌شود. تکرار نصب روی اسکیما و سورس تأییدشده مجاز است؛ نسخهٔ ناشناخته یا مهاجرت ناقص متوقف می‌شود.

در شکست نصب، API و PWA قبلی فقط پس از بررسی سورس و سازگاری اسکیما برمی‌گردند. مهاجرت موفقِ افزودنی حفظ می‌شود؛ بازیابی یا downgrade خودکار دیتابیس انجام نمی‌شود. اگر بررسی نسخهٔ قبلی ممکن نباشد، API خاموش می‌ماند و مسیر پشتیبان اعلام می‌شود. فایل‌های واقعی، کلید رمزگذاری و رمزها در بسته نیستند.

## اعتبارسنجی

نتایج کامل اصلاحات در [گزارش اعتبارسنجی مالی](finance-integrity-validation.md) است: ۸۰۶ آزمون فرانت‌اند، ۱۳۰ آزمون ویرایشگر متن، ۱۰ بررسی مرورگر و ۱٬۳۷۱ مورد بک‌اند بدون شکست غیرمنتظره یا خطای اجرایی. یک XFAIL قدیمی دربارهٔ لینک امضاشدهٔ فایل و یک XPASS قدیمی دربارهٔ وجود جدول ممیزی باقی است؛ این انتظارات تغییر نکرده‌اند. برای انتشار، ۸۱ آزمون مهاجرت، پرداخت و پیامک و ۸ آزمون مسیر نصب نیز موفق شدند. ساخت شمارهٔ `0.9.0` با مبدأهای عمومی API و پشتیبانی موفق شد. نتایج و هش‌ها در `validation.json` بسته ثبت می‌شوند.

نمونهٔ پیامک واقعی و اجرای دریافت اندروید/فورواردکننده هنوز بررسی نشده‌اند. گزارش‌های مرورگر با دادهٔ ساختگی و دیتابیس تست با PostgreSQL موقت اجرا شده‌اند؛ هیچ دادهٔ دستی یا واقعی درگیر نشده است.

## وضعیت انتشار و نصب

این سند وضعیت آماده‌سازی `v0.9.0` را ثبت می‌کند؛ وجود انتشار عمومی باید با GitHub و هش دارایی‌های دانلودشده تأیید شود. نصب روی سرور انجام نشده است. پس از انتشار، دستور نصبِ پین‌شده به هش همان بسته در توضیحات GitHub قرار می‌گیرد؛ اجرای آن روی سرور نیازمند تصمیم جداست.

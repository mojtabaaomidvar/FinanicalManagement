# خانه‌یار 0.6.0 — ۲۲ نوامبر ۲۰۲۶

منبع مستقل بسته روی شاخهٔ `codex/release-0.6.0` بر commit رسمی `e3fa655aaa90dc5056dc8e85799ad1ac658ae732` از نسخهٔ `0.5.0` ساخته شده است. تگ انتشار `v0.6.0` و [صفحهٔ بستهٔ رسمی](https://github.com/mojtabaaomidvar/FinanicalManagement/releases/tag/v0.6.0) هستند. شمارهٔ برنامه و lockfile هر دو `0.6.0` دارند؛ فایل عمومی `version.json` نیز همین نسخه و زمان ساخت مستقل را ارائه می‌کند.

## محدوده

- ده دستهٔ اصلی و ۲۹ زیرگروه برای خوراکی‌ها و دیگر نیازهای خانه، پیشنهاد زندهٔ نام، انتخاب دسته کنار نام و فیلتر موجودی ذخیره‌شده.
- حفظ موجودی واقعی، واحد آزاد و قابل‌ویرایش، موجودی صفر، مصرف و افزایش اعشاری و پیوند خرید به همان قلم انبار. پیشنهاد مقدار خرید یک واحد قابل‌تغییر است.
- ذخیرهٔ دسته در API، snapshot رمزنگاری‌شده، نمایش خوش‌بینانه و صف آفلاین؛ فرمان‌ها و هش رسیدهای قدیمی بازنویسی نمی‌شوند.
- حذف آستانه، وضعیت و اعلان کمبود. دسته‌بندی نام‌های قدیمی شناخته‌شده بدون تغییر نام، مقدار یا یادداشت؛ نام ناشناخته بدون دسته می‌ماند.
- صف پیشنهادهای کالا با نام، دسته و واحد، بدون مقدار موجودی، یادداشت، شناسهٔ خانه یا عضو. بررسی و خروجی صفحهٔ تأییدشده با حساب مستقل پشتیبانی؛ تأیید اپراتور به‌تنهایی کالا را عمومی نمی‌کند.

اصلاحات رسمی بودجه و کیف پول `0.5.0` حفظ شده‌اند. تغییرات ناتمام پیامک، شناسه‌های حساب و راه‌اندازی خانه و بازطراحی مستقل تسویهٔ خرید وارد این بسته نشده‌اند؛ صفحه و قرارداد تسویهٔ قبلی حفظ شده و فقط قفل مرتب اقلام انبار برای جلوگیری از ازدست‌رفتن افزایش‌های هم‌زمان افزوده شده است. فایل آمادهٔ دستورهای غذا کار جداگانه است؛ این انتشار ادعای ورود آن به برنامهٔ غذایی ندارد.

## دیتابیس و نصب

مبنای تولید `0029` است. تنها مهاجرت تازهٔ این شاخه `0029 → 0033_inventory_categories` است. شناسهٔ توصیفی مستقل مانع اشتباه با revision محلی `0033` می‌شود؛ مهاجرت‌های ناتمام پیامک/راه‌اندازی خانه `0030–0032` بسته‌بندی نشده‌اند. محیط دستی و revision محلی آن تغییری نمی‌کنند.

مهاجرت ستون `threshold` و مقادیرش را برای همیشه حذف می‌کند، `category` را می‌افزاید و صف پیشنهادهای ناشناس را می‌سازد. RLS انبار فعال و اجباری باقی می‌ماند. نصب‌کننده پیش از تغییر، PWA، API، دادهٔ کاتالوگ، مهاجرت‌ها و فایل‌های راه‌اندازی را با هش بررسی می‌کند؛ دیتابیس، نقش محدود API و کلید رمزنگاری موجود نیز باید با قرارداد شناخته‌شده مطابق باشند.

API برای پشتیبان یکپارچهٔ دیتابیس و آپلودها متوقف می‌شود. کنترل اثر مهاجرت بر همهٔ رکوردهای موجود داخل همان تراکنش انجام می‌شود؛ فقط افزودن دسته و حذف آستانه از مقایسهٔ رکورد انبار کنار گذاشته می‌شوند. شمارهٔ بازبینی اقلام هنگام دسته‌بندی اولیه حفظ می‌شود تا فرمان‌های آفلاین قدیمی معتبر بمانند؛ تریگر بازبینی پیش از پایان تراکنش دوباره فعال می‌شود. خطای کنترل رکوردها کل مهاجرت را برمی‌گرداند. هیچ downgrade یا بازیابی خودکار گستردهٔ دیتابیس انجام نمی‌شود.

در شکست پیش از اقدام به مهاجرت، API قبلی برمی‌گردد. در شکست پس از اقدام به مهاجرت، API خاموش می‌ماند و پشتیبان حفظ می‌شود؛ نصب‌کنندهٔ تأییدشده را می‌توان دوباره اجرا کرد. API قدیمی نباید روی schema تازه اجرا شود. بازگردانی کامل دیتابیس فقط تصمیم دستی مدیر سرور است، نه رفتار خودکار نصب‌کننده.

کلیدها، تنظیمات پشتیبانی، nginx، داده‌های غیرمرتبط، آپلودها و APK حفظ می‌شوند. بستهٔ اندروید تازه‌ای ساخته نشده است.

## شواهد

۶۸۲ تست فرانت‌اند، ۱۲۲ تست ویرایشگر، TypeScript، ساخت رسمی PWA و پوشش ۴۶۳۴ متن قابل‌ویرایش موفق‌اند. Chrome در عرض‌های ۳۶۰ و ۱۴۴۰ پیکسل دسته‌ها، پیشنهادهای فشرده، ثبت صریح، ماندگاری و فیلتر دسته و پنل بررسی/خروجی و حالت‌های استثنایی را بررسی کرد. هفت بررسی Firefox انبار و دو بررسی شمارهٔ نسخه موفق‌اند. دوازده بررسی نصب‌کننده شامل رد ورودی دست‌کاری‌شده و توقف امن پس از مهاجرت موفق‌اند.

مجموعهٔ مرتبط PostgreSQL روی خوشهٔ موقت مستقل، شامل دسته‌بندی و حریم خصوصی پیشنهادها، مهاجرت و برگشت تراکنش، خرید و قفل موجودی، آفلاین، پشتیبانی، RLS، نقش‌ها، اعلان‌ها، کارها، بودجه، حساب‌ها و عضویت با ۳۱۱ تست موفق شد. سه تست جداگانهٔ کنترل نصب نیز با نقش محدود روی دیتابیس واقعی مستقل موفق شدند؛ مجموعاً ۳۱۴ تست بک‌اند بدون شکست یا کنارگذاری. جزئیات در `validation.json` بسته ثبت می‌شود. اجرای کل مجموعهٔ بک‌اند پس از ۱۲۰۰ ثانیه متوقف شد؛ این گزارش ادعای موفقیت کل مجموعهٔ بک‌اند ندارد. شکست طبقه‌بندی RLS ناشی از جدول‌های ناتمام راه‌اندازی خانه در workspace اصلی، مربوط به این شاخهٔ مستقل نیست؛ آن جدول‌ها وارد بسته نشده‌اند و آزمون طبقه‌بندی در مجموعهٔ انتشار کنار گذاشته نشده است.

هر ۲۶ فایل PWA فعال سرور پیش از انتشار با بستهٔ رسمی `v0.5.0` تطبیق داشت. شواهد خصوصی و منبع جدا در `.local-test/release-v0.6.0/` نگه داشته شده‌اند.

انتشار بسته به معنی نصب آن روی سرور نیست. نصب طبق روال پروژه دستی در VNC با `install.sh` انجام می‌شود. تا تأیید خروجی موفق نصب و نسخهٔ عمومی `0.6.0`، وضعیت نصب این بسته تأییدشده نیست؛ آخرین نسخهٔ فعال مشاهده‌شدهٔ سرور `0.5.0` است.

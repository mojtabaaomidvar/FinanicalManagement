# خانه‌یار 0.5.0 — بودجه‌ها

این بسته بر نسخهٔ رسمی `v0.4.0` ساخته شده است. سقف ماهانه از صفحهٔ بودجه‌ها ویرایش می‌شود؛ ردیف‌های فشرده، جست‌وجو و فیلتر دسته‌ها اضافه شده‌اند. افزایش سقف و ذخیرهٔ تخصیص در یک تراکنش انجام می‌شود، تعارض مدیران برای بررسی دوباره نمایش دارد و حذف تخصیص، تراکنش‌های مالی را نگه می‌دارد. دریافت ناموفق بودجه به‌صورت خطا و تلاش دوباره دیده می‌شود. مدل مشترک خانواده و ماه شمسی حفظ شده‌اند.

شمارهٔ برنامه از `package.json` و lockfile برابر با `0.5.0` است. صفحهٔ تنظیمات، درباره و فایل عمومی `version.json` همان شماره را نشان می‌دهند؛ شناسهٔ زمان ساخت مستقل است. اصلاحات کیف پول `0.4.0` حفظ شده‌اند. تغییرهای مستقل انبار، پیامک و راه‌اندازی خانه وارد این انتشار نشده‌اند.

اعتبارسنجی منبع این نسخه: ۶۷۲ تست برنامه، ۱۱۶ تست مرتبط PostgreSQL در خوشهٔ موقت مستقل، ۱۱۷ تست ویرایشگر متن، پوشش ۴۴۹۷ نوشته، TypeScript، Ruff و ساخت رسمی PWA موفق‌اند. ده بررسی Firefox بودجه در موبایل واقعی ۳۹۰ پیکسل و دسکتاپ، دو بررسی شمارهٔ نسخه و هفت بررسی نصب‌کننده موفق‌اند. هر ۲۶ فایل PWA فعال سرور با `v0.4.0` مطابقت داشت.

نصب‌کنندهٔ اختصاصی `backend/deploy/install-budget-release.sh` API و PWA را با هم به‌روز می‌کند. فایل‌های API و PWA، کلید موجود و revision دیتابیس پیش از نصب بررسی می‌شوند؛ پایگاه داده باید `0029` باشد و نقش API محدود بماند. بسته مهاجرت تازه ندارد و هیچ مهاجرت، بازگردانی دیتابیس یا تغییر nginx/APK اجرا نمی‌کند. نصب از پایگاه داده و آپلودها و نسخهٔ قبلی پشتیبان می‌گیرد، کلیدها و تنظیمات پشتیبانی را حفظ می‌کند و در شکست بررسی سلامت، API و PWA قبلی را بازمی‌گرداند. تکرار نصب نسخهٔ کامل، جایگزینی تازه انجام نمی‌دهد.

انتشار GitHub و نصب سرور دو مرحله‌اند. بستهٔ رسمی روی [تگ `v0.5.0`](https://github.com/mojtabaaomidvar/FinanicalManagement/releases/tag/v0.5.0) ارائه می‌شود؛ نصب طبق روال موجود، دستی در VNC با `install.sh` انجام می‌شود. `validation.json` مشخصات منبع، دامنهٔ نصب، نتایج بررسی و هش فایل‌ها را ثبت می‌کند. وضعیت نصب در زمان بسته‌بندی، تأییدنشده است.

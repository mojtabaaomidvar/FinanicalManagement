# پنل مدیریت سرور و نرم‌افزار خانه‌یار

دامنه با پاسخ «همه چی» تأیید شد: مشاهده و عملیات سرور، حساب‌ها، تنظیمات، بکاپ و بازیابی، و نصب نسخه. این سند انتخاب‌های اجرایی همان دامنه را مشخص می‌کند.

پنل React/TypeScript فارسی با ورود مستقل روی سرویس FastAPI مستقل اجرا می‌شود. قطع API یا دیتابیس خانه‌یار نباید ورود و سابقهٔ عملیات مدیریت را قطع کند. هویت مدیران و نشست‌ها و سابقه در SQLite خصوصی همین سرویس است. مدیر خانواده هیچ مجوز ضمنی برای ورود به این سرویس ندارد. پنل پشتیبانی فعلی و قراردادهای آن حفظ می‌شوند.

رابط از زبان بصری پنل پشتیبانی، قلم وزیرمتن، نردبان فاصله و یک تأکید سبز استفاده می‌کند. نمای کلی وضعیت سرویس‌ها و منابع را در اولویت قرار می‌دهد؛ بخش‌های سرور، کاربران، تنظیمات، پشتیبان‌ها، نسخه‌ها، لاگ‌ها، مدیران و سابقه از ناوبری مشترک باز می‌شوند. متن‌های ثابت در ویرایشگر محلی قابل کشف‌اند.

سرویس وب با کاربر محدود اجرا می‌شود. تنها راه عملیات میزبان یک راه‌انداز ثابت و متعلق به root است که JSON معتبر از stdin می‌گیرد؛ دستور آزاد، مسیر دلخواه، SQL دلخواه و shell ارسالی از مرورگر وجود ندارد. sudoers فقط همان راه‌انداز بدون آرگومان را مجاز می‌کند. عملیات تغییردهنده با قفل میزبان و یک صف پایدار ثبت می‌شوند. درخواست تکراری یک شناسهٔ عملیات را برمی‌گرداند؛ عملیات قطع‌شده خودکار تکرار نمی‌شود.

سه نقش owner، operator و viewer داریم. خواندن برای viewer، عملیات روزانه برای operator، بازیابی/نصب/حساب مدیران برای owner است. نشست کوکی HttpOnly و SameSite=Strict دارد؛ مبدأ دقیق، CSRF، محدودیت تلاش ورود و انقضا بررسی می‌شوند. محیط تولید رمز قوی و TOTP می‌خواهد. پیش‌نمایش عملیات به همان نشست وابسته و کوتاه‌عمر است؛ اجرای عملیات نیازمند تأیید رمز و در تولید کد دومرحله‌ای است. رمزها و کلیدهای درگاه در سابقه و پاسخ وضعیت برنمی‌گردند.

قابلیت‌ها:

- منابع واقعی میزبان، دیسک، uptime، سلامت واقعی اتصال دیتابیس، نسخه و وضعیت API، Docker و nginx؛ شروع، توقف و راه‌اندازی مجدد API/دیتابیس و اعتبارسنجی و بارگذاری nginx؛ تمدید گواهی؛ راه‌اندازی مجدد زمان‌بندی‌شدهٔ میزبان و لغو آن.
- فهرست و جست‌وجوی کاربران با شمارهٔ ماسک‌شده و کد پشتیبانی؛ تعلیق/رفع تعلیق حساب فعال و ابطال نشست‌ها. دسترسی مستقیم به اسناد و متن مالی وارد پنل نمی‌شود.
- توقف ثبت‌نام، حالت تعمیرات، فعال‌بودن دستیار، OTP و تنظیمات مجاز پیامک و هوش مصنوعی. کلید رمزنگاری و تنظیمات خارج این فهرست حفظ می‌شوند. وضعیت تعمیرات و ثبت‌نام در خود API اعمال می‌شود.
- پشتیبان سازگار از دیتابیس، آپلودها، تنظیمات و وب با توقف کوتاه API، manifest و SHA-256؛ بررسی، دریافت و بازیابی از پشتیبان شناخته‌شده. بازیابی پیش از تغییر یک بکاپ جدید می‌گیرد؛ تصویر API و فایل‌ها و schema با هم برمی‌گردند. پشتیبان روزانه از timer مستقل میزبان قابل فعال‌سازی است.
- دریافت بسته از release رسمی همین مخزن با tag معتبر و کنترل SHA-256، بررسی آرشیو و نصب با نصب‌کنندهٔ داخل همان بسته. پیش از نصب بکاپ کامل مدیریت گرفته می‌شود. مسیر منبع نصب‌شده حفظ می‌شود. مهاجرت/بازگشت عمومی و حدسی انجام نمی‌شود.
- لاگ محدود و پالایش‌شدهٔ سرویس‌های مشخص، مدیران مستقل، ابطال نشست، سابقهٔ عملیات و نتیجهٔ موفق/ناموفق/قطع‌شده.

ساخت مستقل پنل هیچ service worker یا پروکسی تولید ندارد. نمونهٔ محلی روی loopback با driver آزمایشی مستقل کار می‌کند و در رابط مشخص است که عملیات شبیه‌سازی می‌شوند. داده‌های محیط دستی ۵۷۰۰ و پیش‌نمایش ۵۷۰۱ تغییر نمی‌کنند. راه‌انداز تولید و قالب nginx/systemd/sudoers آماده می‌شوند؛ نصب روی سرور واقعی جزء این تغییر محلی نیست.

اعتبارسنجی شامل تست هویت/مجوز/CSRF/تکرار/قفل/حفاظت آخرین مالک، مرز دستورها و آرشیو و بازیابی، کنترل تعمیرات و ثبت‌نام، TypeScript و ساخت مستقل و پوشش متن، و مرورگر در عرض ۳۶۰ و ۱۴۴۰ است. عملیات واقعی root روی VPS فقط پس از نصب و بررسی همان محیط قابل ادعاست.

# محیط تست محلی خانه‌یار

این محیط برای آزمون دستی داخل مرورگر، بدون شمارهٔ واقعی، آماده شده است. فرانت‌اند و بک‌اند واقعی برنامه اجرا می‌شوند؛ دیتابیس، فایل‌های آپلودی و نشست مرورگر از برنامهٔ اصلی جدا هستند. پیامک و فضای ذخیره‌سازی ابری در این محیط خاموش‌اند.

## بازکردن برنامه

روی `start-test.bat` در ریشهٔ پروژه دوبار کلیک کنید. پس از راه‌اندازی، مرورگر با نشانی زیر باز می‌شود:

<http://127.0.0.1:5700>

اگر صفحهٔ خوش‌آمدگویی را دیدید، «ورود» را بزنید. در صفحهٔ ورود، شمارهٔ ساختگی و رمز یکی از حساب‌های آماده را وارد کنید؛ نیازی به ثبت‌نام یا دریافت کد پیامکی نیست.

| حساب | شمارهٔ ورود | رمز |
| --- | --- | --- |
| مدیر خانواده (`owner`) | `09000000001` | `Test12345!` |
| عضو یک | `09000000002` | `Test12345!` |
| عضو دو | `09000000003` | `Test12345!` |
| مدیر دوم (`admin`) | `09000000004` | `Test12345!` |

این شماره‌ها فقط شناسهٔ حساب‌های آزمایشی هستند. همهٔ حساب‌ها عضو یک خانوادهٔ آزمایشی‌اند؛ هرکدام کیف‌پول و هزینهٔ نمونه دارند. مبالغ به تومان‌اند.

## آزمون ویرایش تراکنش

1. با «عضو یک» وارد شوید و یک تراکنش منتسب به خودش را ویرایش کنید. مبلغ جدید باید پس از تازه‌سازی صفحه یا بستن و بازکردن مرورگر هم باقی بماند.
2. تراکنش منتسب به «عضو دو» را بررسی کنید. عضو یک مجوز ویرایش آن را ندارد؛ اگر رابط کاربری دکمهٔ ویرایش را نمایش دهد، ذخیرهٔ تغییر باید رد شود.
3. از حساب خارج شوید و با حساب مدیر وارد شوید. مدیر باید بتواند تراکنش هر دو عضو را ویرایش کند.
4. برای آزمون تغییر عضو منتسب، مدیر می‌تواند تراکنش را به عضو دیگری نسبت دهد؛ عضو عادی نمی‌تواند تراکنش خودش را به دیگری نسبت دهد.

می‌توانید دادهٔ آزمایشی بسازید، ویرایش کنید یا حذف کنید. راه‌اندازی دوباره، تغییرهای شما را پاک نمی‌کند و هزینه‌های نمونهٔ حذف‌شده دوباره ساخته نمی‌شوند.

## توقف و راه‌اندازی دوباره

برای توقف روی `stop-test.bat` دوبار کلیک کنید. برای اجرای دوباره از `start-test.bat` استفاده کنید. دیتابیس و فایل‌ها در پوشهٔ نادیده‌گرفته‌شدهٔ `.local-test/` حفظ می‌شوند؛ تنظیمات خصوصی و لاگ‌ها هم در همین پوشه‌اند.

معادل دستوری:

```powershell
npm run sandbox
npm run sandbox:check
npm run sandbox:offline-check
npm run sandbox:tasks-check
npm run sandbox:documents-check
npm run sandbox:meals-check
npm run sandbox:equipment-check
npm run sandbox:vehicles-check
npm run sandbox:goals-check
npm run sandbox:activities-check
npm run sandbox:children-check
npm run sandbox:pets-check
npm run sandbox:pets-check -- --back-only
npm run sandbox:profile-check
npm run sandbox:birthday-calendar-check
npm run sandbox:stop
```

`sandbox:check` ورود، مجوز ویرایش و ماندگاری داده را از مسیر واقعی HTTP بررسی می‌کند. برای این آزمون تراکنش‌های موقت مخصوص می‌سازد و پس از پایان همان‌ها را حذف می‌کند؛ دادهٔ تست دستی تغییر نمی‌کند.

`sandbox:profile-check` ثبت، تغییر و حذف تاریخ تولد و نمایش فوری تقویم، آپلود و نمایش عکس در دکمهٔ پروفایل صفحهٔ خانه، دسترسی تنظیمات بدون کاشی و حالت خطای تصویر را در مرورگر بررسی می‌کند. پروفایل حساب ساختگی و رویدادهای تولد قبلی را برمی‌گرداند و فقط فایل و نشست‌های آزمایشی خودش را پاک می‌کند.

`sandbox:birthday-calendar-check` تولد ۱۵ آبان ۱۳۴۰ مدیر آزمایشی را در چند سال گذشته و آینده و بازهٔ ۳۰ روز آیندهٔ تقویم بررسی می‌کند. پروفایل، عکس و رویدادها را ویرایش نمی‌کند و فقط نشست‌های آزمون خودش را می‌بندد؛ ساعت آزمایشی فقط در مرورگر تغییر می‌کند.

`sandbox:offline-check` آزمون مرورگر Edge برای خرید و انبار آفلاین است: قطع شبکه و بازکردن دوباره، ارسال خودکار، گم‌شدن پاسخ بدون ثبت تکراری، تعارض عضو دوم، پاک‌سازی خروج و ورود حساب دیگر. دادهٔ موقت خودش را پس از آزمون پاک می‌کند. جزئیات و نتیجهٔ تأیید در [خرید و انبار آفلاین](offline-shopping-inventory.md) ثبت شده است.

`sandbox:tasks-check` کارهای خانه را از مسیر واقعی مرورگر بررسی می‌کند: ثبت و واگذاری و موعد شمسی، مجوز سازنده و مسئول و مدیر دوم، تأیید صریح انجام‌شدن و لغو بدون تغییر، عکس اختیاری و پیش‌نمایش و مشاهدهٔ مشترک پس از بارگذاری مجدد، بازکردن دوباره، حفظ آفلاین عکس و تغییر، ارسال بدون تکرار، یادآور و خاموشی آن، تعارض و رد مجوز، خروج و ورود حساب دیگر. دادهٔ موقت خودش را پاک می‌کند و تنظیم اعلان حساب آزمایشی را به حالت قبلی برمی‌گرداند. راهنما: [کارهای خانه](household-tasks.md).

## مشخصات اجرا

`sandbox:documents-check` ثبت عکس/PDF، ویرایش و حذف، دسترسی خصوصی و مشترک، یادآور تاریخ اعتبار، دریافت فایل پس از مجوز، قطع اتصال و عرض موبایل را بررسی می‌کند. فقط اسناد و نشست‌های موقت خودش را پاک می‌کند. کلید مستقل رمزنگاری اسناد هنگام راه‌اندازی ساخته و در تنظیمات خصوصی همین محیط حفظ می‌شود؛ راه‌اندازی دوباره کلید یا دادهٔ دستی را عوض نمی‌کند.

`sandbox:meals-check` برنامهٔ غذایی را در Edge و عرض موبایل بررسی می‌کند: ثبت و ویرایش و حذف غذا و وعده، هفتهٔ شمسی، مجوز سازنده و نمایش فقط‌خواندنی عضو دیگر، جمع‌کردن مواد و مقدار اعشاری فارسی، انتخاب لیست مقصد، حفظ قلم خرید موجود و دادهٔ انبار و مالی، تلاش دوباره پس از گم‌شدن پاسخ بدون ثبت تکراری، و پاک‌شدن فرم و دادهٔ برنامه در قطع اتصال. فقط غذاها، وعده‌ها، لیست‌ها و نشست‌های موقت خودش را پاک می‌کند؛ برای حفظ برنامهٔ تست دستی، دست‌کم دو وعدهٔ خالی در هفتهٔ جاری لازم است. راهنما و نتیجهٔ اعتبارسنجی در [برنامهٔ غذایی خانواده](household-meals.md) ثبت شده‌اند.

`sandbox:equipment-check` وسایل خانه را در Edge و عرض موبایل بررسی می‌کند: ثبت و ویرایش و حذف وسیله، تاریخ‌های شمسی، انتخاب سند مشترک و کار موجود، دریافت واقعی فایل با مجوز، سرویس و گارانتی در مرکز اعلان و بازکردن جزئیات همان وسیله، ثبت اتمیک سرویس و موعد بعدی، تلاش دوباره پس از گم‌شدن پاسخ بدون ثبت تکراری، مجوز عضو دیگر، ماندگاری سابقه، انصراف از حذف و پاک‌شدن فرم و داده در قطع اتصال. حفظ اسناد، کارها، موجودی انبار و دادهٔ مالی هم بررسی می‌شود. اسکریپت فقط داده و نشست‌های موقت خودش را پاک می‌کند و تنظیم اعلان حساب آزمایشی را برمی‌گرداند. راهنما: [وسایل خانه و سرویس‌های دوره‌ای](household-equipment.md).

`sandbox:vehicles-check` خودرو و نگهداری را در Edge و عرض موبایل بررسی می‌کند: ثبت، ویرایش و حذف خودرو، تاریخ‌های شمسی و کیلومتر، سند مشترک و کار موجود، دریافت واقعی فایل و پاک‌شدن اطلاعات سند پس از رد مجوز، اعلان سرویس/بیمه/معاینه و مقصد همان خودرو، ثبت سرویس همراه هزینهٔ حمل‌ونقل و ورود به همان هزینه در مالی، تلاش دوباره پس از گم‌شدن پاسخ بدون سابقه یا هزینهٔ تکراری، مبلغ فعلی مالی، مجوز عضو دیگر، پاک‌شدن داده و فرم هنگام قطع اتصال و کنارگذاشتن پاسخ دیررس مالی. تبدیل ریال/تومان با قواعد مشترک انجام و در آزمون قواعد هر دو واحد بررسی می‌شود. حذف خودرو هزینه‌های مالی، سند و کار را حفظ می‌کند. اسکریپت فقط داده و نشست‌های موقت خودش را پاک می‌کند و تنظیم اعلان حساب آزمایشی را برمی‌گرداند. راهنما و نتیجهٔ اعتبارسنجی: [خودرو و نگهداری](household-vehicles.md).

- مرورگر: `127.0.0.1:5700`
`sandbox:activities-check` ثبت و ویرایش برنامهٔ خانوادگی، تاریخ شمسی و شرکت‌کنندگان، تغییر وضعیت، یادآور، نمایش همان برنامه در تقویم و ورود به جزئیات، مجوز سازنده/مدیر، پاک‌سازی آفلاین و رد پاسخ دیررس را در Edge و عرض موبایل بررسی می‌کند. فقط داده و نشست‌های موقت خودش را پاک و تنظیم اعلان را برمی‌گرداند. راهنما: [تفریح و برنامه‌های خانوادگی](household-activities.md).

`sandbox:children-check` ثبت فرزند بدون شماره، تولد شمسی و سن، ویرایش مدیر، کار مستقیم و صف‌شده با مسئول فرزند معرفی‌شده، برنامهٔ خانوادگی با همان شناسه، تولد و اعلان یکتا، منع ویرایش عضو عادی، قطع اتصال و پاسخ دیررس را در Edge و عرض موبایل بررسی می‌کند. حذف عضو از مسیر فعلی و حفظ کار و برنامه هم آزموده می‌شوند. فقط داده و نشست‌های موقت خودش را حذف و ترجیحات اعلان را برمی‌گرداند. راهنما: [فرزندان و برنامه‌های آن‌ها](household-children.md).

`sandbox:pets-check` پروفایل حیوان و تولد شمسی، مراقبت با همان شناسهٔ کار و تلاش دوباره بدون ثبت تکراری، مجوز مدیر و مسئول، تکمیل و بازگشایی و یادآور، ویرایش مستقیم و آفلاین با حفظ ارتباط، پاک‌سازی فرم و داده در قطع اتصال و رد پاسخ دیررس را در Edge و عرض موبایل بررسی می‌کند. حذف حیوان کارها را حفظ و نسخهٔ کار را تغییر می‌دهد؛ نام بلند و نبود سرریز افقی هم بررسی می‌شوند. فقط داده و نشست‌های موقت خودش را حذف و تنظیم اعلان را برمی‌گرداند. راهنما: [حیوانات خانگی و مراقبت](household-pets.md).

گزینهٔ `--back-only` بازگشت واقعی مرورگر از فرم مراقبت به جزئیات، فهرست حیوانات و هاب را بررسی می‌کند؛ فرم ذخیره نمی‌شود و مرورگر در نرم‌افزار می‌ماند. نمایش نام بلند در جزئیات و تأیید حذف هم در این بررسی پوشش داده می‌شود.

- مرورگر: `127.0.0.1:5700`
`sandbox:goals-check` ثبت و ویرایش هدف و آرزو، موعد شمسی، تکمیل و بازگشایی، یادآور و مقصد جزئیات، جداسازی اعضا و مدیر، پاک‌شدن فرم و داده در قطع اتصال، رد پاسخ دیررس و حذف را در Edge و عرض موبایل بررسی می‌کند. فقط موارد و نشست‌های آزمایشی خودش را حذف می‌کند و ترجیحات اعلان عضو را برمی‌گرداند. راهنما: [اهداف و آرزوهای شخصی](household-goals.md).

- مرورگر: `127.0.0.1:5700`
- API: `127.0.0.1:5800`
- PostgreSQL: `127.0.0.1:55439`، دیتابیس `khaneyar_local_sandbox`
- نقش اتصال API: `khaneyar_sandbox` با `NOSUPERUSER` و `NOBYPASSRLS`؛ محدودیت‌های خانواده در دیتابیس فعال‌اند.
- حالت Vite: `local-sandbox`؛ آدرس API در `.env.local` برای این حالت کنار گذاشته می‌شود و درخواست‌ها فقط به پروکسی محلی می‌روند.
- عنوان تب مرورگر و نام خانواده، آزمایشی‌بودن محیط را مشخص می‌کنند.
- راه‌انداز نسخهٔ ساخته‌شدهٔ PWA را نمایش می‌دهد تا قطع اینترنت و بازکردن دوباره هم قابل آزمون باشند؛ پس از تغییر کد، توقف و شروع دوباره نسخهٔ تازه را می‌سازد.

این محیط فقط روی همین کامپیوتر باز می‌شود. دادهٔ واقعی از سرور به آن منتقل نمی‌شود. برای نصب روی کامپیوتر دیگر، Node، وابستگی‌های پروژه، Python با وابستگی‌های بک‌اند و ابزارهای PostgreSQL لازم‌اند. مسیر `bin` PostgreSQL از نصب موجود یا ابزار تست قبلی پیدا می‌شود؛ در صورت نیاز می‌توان `KHANEYAR_SANDBOX_PG_BIN` را تعیین کرد.

اگر راه‌اندازی خطا داد، پیام خطا و لاگ‌های `.local-test/` محل مشکل را نشان می‌دهند. پورت اشغال‌شده خودکار عوض نمی‌شود؛ این رفتار از بازشدن برنامه روی یک اتصال اشتباه جلوگیری می‌کند.
